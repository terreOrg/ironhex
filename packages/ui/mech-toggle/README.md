# Механический тумблер `<mech-toggle>`

Автономный Web Component для интерфейса кабины IRON HEX: вид спереди, два фиксированных положения, анимация рычага и индикатор питания. Написан на JavaScript/CSS без зависимостей, внешних изображений и сборки. Стили изолированы через Shadow DOM.

## Файлы и демонстрация

- `mech-toggle.js` — компонент для подключения в игру.
- `demo.html` — автономная демонстрация; скачайте и откройте в браузере. Содержит встроенную копию компонента, чтобы работать без сервера.

Это переиспользуемый элемент управления. Он ещё не подключён к игровому движку и не включён в сборку `dist`.

## Быстрое подключение

Скопируйте `mech-toggle.js` в каталог статических файлов вашего приложения. Подключите скрипт перед кодом, который обращается к компоненту:

```html
<script src="./mech-toggle.js"></script>
<mech-toggle id="reactor" label="Питание реактора"></mech-toggle>
<script>
  const reactor = document.getElementById('reactor');
  reactor.addEventListener('change', (event) => {
    const enabled = event.detail.checked;
    console.log('Новое состояние:', enabled);
    // Здесь вызовите команду вашего приложения.
  });
</script>
```

Для приложения с модульной сборкой можно импортировать файл ради регистрации элемента:

```js
import './mech-toggle.js';
```

При асинхронной загрузке скрипта дождитесь регистрации:

```js
await customElements.whenDefined('mech-toggle');
```

## Параметры

| API | Значение |
| --- | --- |
| `checked` / `.checked` | Булев атрибут / свойство. По умолчанию выключен. |
| `disabled` / `.disabled` | Блокировка взаимодействия. По умолчанию выключена. |
| `label` | Доступное название для экранного диктора; по умолчанию «Тумблер». |
| `--toggle-width` | Ширина; по умолчанию `160px`. Высота пропорциональна. |
| `change` | Событие пользовательского переключения: `detail.checked`, `bubbles: true`, `composed: true`. |

```html
<mech-toggle checked label="Подсветка" style="--toggle-width: 100px"></mech-toggle>
<mech-toggle disabled label="Недоступная система"></mech-toggle>
```

```js
reactor.checked = true;
reactor.disabled = false;
reactor.setAttribute('label', 'Питание реактора');
```

Программное изменение `.checked` не вызывает `change`. Атрибуты булевы: `checked="false"` тоже означает включённое состояние. Для выключения используйте `.checked = false` или `removeAttribute('checked')`.

## Подключение к логике игры

Обрабатывайте `change` в контроллере интерфейса, проверяйте допустимость команды в движке/на сервере и синхронизируйте `.checked` с подтверждённым состоянием. На время запроса можно установить `.disabled = true`; при отказе восстановить прежнее состояние. Компонент самостоятельно не выполняет сетевые запросы и не сохраняет состояние после перезагрузки.

Несколько тумблеров работают независимо. Не присваивайте им одинаковые `id`. Это переключатель с сохранением положения, а не кнопка, действующая только во время удержания. Автоматическая отправка значения через HTML-форму не реализована.

## Управление и доступность

- Нажатие мышью или касание переключает состояние.
- Tab переводит фокус; Enter и пробел активируют внутреннюю нативную кнопку.
- Используются `role="switch"`, `aria-checked` и доступное название.
- Предусмотрены видимый фокус, блокировка и отключение анимации при `prefers-reduced-motion`.

## Проверка

Синтаксис: `node --check packages/ui/mech-toggle/mech-toggle.js`.

Ручная проверка: откройте `demo.html`, переключите тумблер мышью, затем клавиатурой; включите блокировку и убедитесь, что состояние не меняется. Полная браузерная проверка при подготовке публикации не выполнена: среда не позволяет запустить Chromium.
